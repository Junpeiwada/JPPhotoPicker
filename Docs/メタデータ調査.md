# メタデータ調査（Sony α の連写・インターバル判別）

PhotoPicker の設計前提になる、ソニー機 JPG のメタデータの調査結果。
調査日: 2026-09-29 ／ 調査ツール: ExifTool 13.50

## 結論

- **連写は判別できる。** Sony MakerNote の `ReleaseMode` と `SequenceNumber` を見ればよい
- **インターバル撮影は判別できない。** 通常の単写と同じ値（`Normal` / `Single`）になっている
- JPG には **1920×1080 のプレビュー**（MPF、約100KB）と **160×120 のサムネイル**（約4KB）が埋め込まれている。本体（8640×4864、約7MB）をデコードせずに一覧・閲覧表示ができる

## 調査サンプル

| 項目 | 内容 |
|---|---|
| 機種 | ILCE-1M2（α1 II） |
| 形式 | JPG（ARW と同時記録。今回調べたのは JPG だけ） |
| 連写 | 47枚（A1_07866〜A1_08221、2026-09-27 撮影、選別済みのためコマ番号は飛び飛び） |
| インターバル | 1枚（A1_04911、2026-04-26 撮影、10秒露光） |
| 通常の単写 | **サンプルなし**（未解明タグの比較に必要。後述） |

## 連写判別に使うタグ

どちらも Sony MakerNote（Exif `0x927C`）の IFD 直下にある通常のエントリで、暗号化されていない。

| タグ ID | 名前 | 型 | 値 |
|---|---|---|---|
| `0xB049` | ReleaseMode | int16u | `0` = Normal（単写）、`2` = Continuous（連写）。ほかにブラケットなどの値もある |
| `0xB04A` | SequenceNumber | int16u | `0` = Single（単写）、`1` 以上 = 連写の中で何枚目か |

実測値:

| ファイル | ReleaseMode | SequenceNumber |
|---|---|---|
| A1_04911（インターバル） | 0 (Normal) | 0 (Single) |
| A1_07913（連写） | 2 (Continuous) | 1 |
| A1_08221（連写） | 2 (Continuous) | 13 |

参考として、暗号化ブロック（Tag9400 / Tag2010 系）の中にも `ReleaseMode2`、`SequenceImageNumber`、`SequenceFileNumber`、`SequenceLength`（`Continuous` / `1 shot` / `1 file`）がある。復号が必要になるので、PhotoPicker では使わない。

### 連写グループの区切り方

**「ファイル番号 − SequenceNumber + 1」（その連写の先頭コマの番号）が同じコマを、同じグループにする。** カメラは1コマごとにファイル番号を1つ進めるので、1枚目が選別で消えていても先頭の番号は求められる。

サンプル47枚での実測（抜粋）:

| ファイル | 撮影時刻 | SequenceNumber | 先頭の番号 |
|---|---|---|---|
| A1_07866 | 08:31:55.873 | 3 | 7864 |
| A1_07868 | 08:31:55.973 | 5 | 7864 |
| A1_07873 | 08:31:56.457 | 4 | 7870 |
| A1_08195 | 08:35:56.038 | 1 | 8195 |
| A1_08200 | 08:35:56.288 | 6 | 8195 |
| A1_08209 | 08:35:56.972 | 1 | 8209 |

- 47枚すべてで、先頭の番号は撮影時刻の順に増えていき、矛盾はなかった
- `SequenceNumber == 1` だけで区切る方法は、1枚目が抜けたフォルダでは使えない（47枚中で 1 のコマは7枚だけ）
- 撮影時刻の差で区切る方法も使えない。A1_07868 と A1_07873 は別の連写なのに、撮影時刻の差は 0.48 秒しかない
- ファイル番号が一周したとき（99999 → 00001）は、またがった連写が2つに分かれる。まれなので対応しない

## フォーカス位置に使うタグ

等倍表示でフォーカス位置を拡大するために使う。どちらも Sony MakerNote の IFD 直下にあり、暗号化されていない。

| タグ ID | 名前 | 型 | 値 |
|---|---|---|---|
| `0x2027` | FocusLocation | int16u[4] | 画像の幅、高さ、X、Y（ピクセル）。`0x204A` FocusLocation2 も同じ値だった |
| `0x2037` | FocusFrameSize | int16u[3] | 枠の幅、高さ、有効フラグ（`257` = 有効、`0` = 無効） |

実測値（全49枚）:

| ファイル | FocusMode | FocusLocation | FocusFrameSize | 備考 |
|---|---|---|---|---|
| A1_04911（インターバル） | 0 (MF) | 8640 4864 4320 2432 | 0 0 0 | 画像のちょうど中心。枠は無効 |
| A1_01309（縦位置、Orientation = 8） | 3 (AF-C) | 8640 4864 4563 2918 | 189 193 257 | 幅・高さは横長のまま |
| A1_07913（連写） | 3 (AF-C) | 8640 4864 5805 2452 | 891 392 257 | 被写体を追っている |
| A1_07927 / A1_08072（連写） | 3 (AF-C) | 8640 4864 4333 2442 | 6804 4783 0 | 枠が無効。位置はほぼ中心 |

- 連写の47枚中45枚で枠が有効で、位置はコマごとに被写体を追って動いていた
- 枠が無効（3番目が `0`）のときは、位置も当てにならないので中心として扱う
- 縦位置のサンプル A1_01309（Orientation = 8）でも `FocusLocation` は `8640 4864 4563 2918` で、幅・高さは横長のままだった。**座標は回転する前の画素の並び（センサーの向き）で記録されている**と判断した
  - 回転前の画像にそのまま枠を描くと、編隊の右後ろのスモークの上に乗った。表示の向きの座標とみなすなど、ほかの解釈で置くと何もない空に落ちる
  - 撮影時にスモークでピントが合っていたかどうかは、撮影者に確認していない

## JPG ファイルの構造（A1_07913）

| 要素 | 位置・サイズ | 用途 |
|---|---|---|
| APP1（Exif） | ファイル先頭、約44KB | Exif、Sony MakerNote（117エントリ、リトルエンディアン）、サムネイル |
| MakerNote ヘッダー | `"SONY DSC \0\0\0"`（12バイト）の直後に IFD エントリ数 | オフセットは TIFF ヘッダー基準 |
| IFD1 サムネイル | 160×120、4,421バイト | フィルムストリップ |
| MPF 2枚目（PreviewImage） | 1920×1080、106,072バイト、ファイル後方（MPImageStart = 7,299,072） | 大プレビュー |
| 本体 | 8640×4864、約7MB | 等倍表示のときだけデコードする |

- 撮影時刻はミリ秒まで取れる（`SubSecTimeOriginal`、例 `08:32:00.761+09:00`）。並べ替えと区切りに使う
- 連写の実測間隔は 100ms 前後（例: 08:31:55.873 → 08:31:55.973）
- Orientation は IFD0 にある

## インターバル撮影について

連写（A1_07913）と全タグを比べて値が違ったのは、撮影条件（フォーカス、DRO、RAW 形式、レンズ補正など）だけだった。`interval` や `timelapse` にあたるタグは見つからなかった。

意味の分かっていない Sony タグにも差がある:

| タグ | インターバル | 連写 |
|---|---|---|
| `Sony_0x2025` | `1 0 0 0` | `7 3 0 0` |
| `Sony_0x203d` | `1` | `47` |

比較相手が連写しかないため、これがインターバルの印なのか、単写と連写の違いなのかは分からない。通常の単写を1枚撮って比べれば確定できる。PhotoPicker ではインターバルを区別しない（[仕様.md](仕様.md) 参照）ので、この調査は保留にする。

## 未確認事項

- ~~ARW 側の埋め込みプレビューのサイズと構造、MakerNote のタグ~~ → 2026-09-29 に α1 II（ILCE-1M2）の ARW で確認した:
  - MakerNote（ExifIFD の 0x927C）は `"SONY DSC "` ヘッダーが無く、先頭がすぐ IFD（exiftool の `MakerNoteSony5`）。値のオフセットは TIFF 先頭基準。ファイル先頭から約 5KB の位置にあり、長さ約 38KB
  - `0xB049` ReleaseMode・`0xB04A` SequenceNumber・`0x2027` FocusLocation（8640×4864 基準）・`0x2037` FocusFrameSize は JPG と同じタグ・同じ意味で入っている
  - 埋め込みプレビューは IFD0 の 0x0201/0x0202（1920×1080、60〜90KB、オフセット 204962 付近）。IFD2 にもっと大きい JpgFromRaw（約 2MB）があるが、今は使っていない
  - IFD1 のサムネイルは 160×120 で小さい。ImageIO に ARW からサムネイルを作らせると 1 枚 約 300ms かかった
- α1 II 以外の機種で、同じタグ・値になるかどうか
- ブラケット、ドライブモード「連写 Lo/Mid/Hi」ごとの `ReleaseMode` の値の違い
- Orientation = 6（反対向きの縦位置）のサンプル（8 と同じく回転前の座標になるはず）

## 確認コマンド

```bash
# 連写関連タグの一覧
exiftool -T -FileName -SubSecDateTimeOriginal -ReleaseMode -SequenceNumber *.JPG

# 生の数値（-n）とタグ ID（-H）
exiftool -a -H -G1 -n -ReleaseMode -SequenceNumber FILE.JPG

# 埋め込みプレビューの取り出し
# フォーカス位置と枠
exiftool -T -n -FileName -Orientation -FocusMode -FocusLocation -FocusFrameSize *.JPG

exiftool -b -PreviewImage FILE.JPG > preview.jpg
exiftool -b -ThumbnailImage FILE.JPG > thumb.jpg
```
